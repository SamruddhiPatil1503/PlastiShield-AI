# PlastiShield AI
### AI-Powered Plastic Waste Identification and Recycling Guidance Android Application

## About the Project
PlastiShield AI is an Android application designed to promote plastic waste identification, recycling awareness, and responsible waste management using AI-assisted image analysis.

The project supports the long-term vision of converting recycled plastic waste into useful products, including eco-friendly waterproofing paint.

## Features
- Capture waste images using the camera.
- Upload images from the gallery.
- AI-assisted waste image analysis.
- Display estimated waste category and recycling guidance.
- Save and view scan history.
- Material suitability educational guide.
- Plastic waste collection and reuse tracker.
- Impact dashboard for recorded waste data.
- Recycling guide for different waste categories.

## Technologies Used
- Java
- XML
- Android Studio
- Firebase Authentication
- Cloud Firestore
- Firebase AI Logic
- Gemini
- Firebase App Check

## Application Workflow
1. Capture or upload a waste image.
2. Submit the image for AI-assisted analysis.
3. View the estimated waste category and guidance.
4. Save and review scan history.
5. Record plastic waste collection and reuse.
6. View recorded data in the Impact Dashboard.

## Hardware Used
- Android smartphone
- Smartphone camera
- Laptop/Desktop for development

The current application does not use external Arduino, ESP8266, or physical waste-sensing hardware.

## Installation
1. Download or clone this repository.
2. Open the project in Android Studio.
3. Configure your Firebase project.
4. Add your own `google-services.json` file inside the `app` folder.
5. Sync Gradle.
6. Build and run the application.

Do not upload private credentials, signing keys, or API secrets to this public repository.

## Testing
The developer has tested the application on an Android device and reported successful operation of the main application modules, including image selection, AI results, scan history, material suitability, waste tracking, impact dashboard, and recycling guide.

## Limitations
- AI results are estimates and are not laboratory-confirmed polymer identification.
- Exact plastic composition requires appropriate material testing.
- Waterproof paint performance requires separate formulation and laboratory validation.
- Dashboard calculations depend on user-entered records.

## Future Scope
- Improve waste classification.
- Add more recycling categories.
- Integrate verified material-testing information.
- Explore IoT-based waste monitoring.
- Connect plastic waste tracking with recycled-plastic product development.

## Project Vision
To encourage responsible plastic waste management and support the development of sustainable products using recycled plastic.

## Disclaimer
This application is developed for educational and project demonstration purposes. AI-generated results must be independently verified before material-selection or manufacturing decisions.
